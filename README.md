# Darkplace — сервер-диспетчер

Сервер удалённого управления Windows-ПК: REST API + WebSocket, к которому
подключаются агенты. Разворачивается на Node-хостинге (Railway, Render, VPS).

## Запуск

```bash
npm install
npm start
```

## Переменные окружения (обязательно задать на хостинге)

| Переменная   | Зачем                                                          |
|--------------|----------------------------------------------------------------|
| `PORT`       | Порт (хостинг обычно задаёт сам)                               |
| `RC_KEYWORD` | Ключевое слово для входа в панель                              |
| `JWT_SECRET` | Секрет подписи токенов — **обязательно сменить перед деплоем** |
| `RC_CERT`/`RC_KEY` | (опционально) TLS-сертификат и ключ для https/wss        |

Панель защищена ключевым словом: `POST /api/login` с телом `{"keyword": "…"}`
возвращает JWT-токен; остальные `/api/*` принимаются только с заголовком
`Authorization: Bearer <токен>`.

Шаблон — `server/.env.example`.
